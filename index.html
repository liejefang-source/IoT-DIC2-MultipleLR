物聯網邊緣端推論 (Edge AI Inference)

多元線性迴歸模型在 IoT 領域擁有極大優勢。其推論僅需一次矩陣向量點積 ŷ = X · β，記憶體佔用小於 1 KB，且在微控制器 (如 ESP32、Raspberry Pi、STM32) 上的計算延遲低於 1 毫秒，極度適合邊緣感測器設備即時預警與節能推論。

最小平方法數理核心 (OLS Normal Equation)

本平台內建完整線性代數運算引擎，透過正規方程式 β = (XᵀX)⁻¹Xᵀy 進行解析解求取，並內建高斯-約當 (Gauss-Jordan) 消去法搭配 Tikhonov 脊微正則化 (1e-7)，確保多重共線性下數值計算穩定性與精準反矩陣求解。

GitHub Pages 部署與繳交步驟

本專案已完全建立完畢，包含官方 GitHub Pages 自動部署工作流 .github/workflows/pages.yml。請依照以下步驟啟用並繳交作業：

  1. 步驟 1: 推播程式碼至您的 GitHub 儲存庫

    在專案目錄下執行 Git 指令：

    git init
git add .
git commit -m "feat: complete DIC-2 multiple linear regression project"
git branch -M main
git remote add origin https://github.com/[您的GitHub帳號]/IoT-DIC2-MultipleLR.git
git push -u origin main
  2. 步驟 2: 前往 GitHub 儲存庫設定啟用 Pages

    開啟您的 GitHub 儲存庫頁面，點選 Settings → 左側 Pages。

    方式一 (推薦 · 官方 GitHub Actions)：
    在 Build and deployment 的 Source 下拉選單中選擇 GitHub Actions。
    系統會自動偵測 pages.yml，約 30 秒內自動完成部署上線！
    方式二 (傳統分支)：
    在 Source 選擇 Deploy from a branch，Branch 選擇 main / / (root)，點擊 Save。
  3. 步驟 3: 複製公開網址繳交作業

    您的預計公開網址格式為：

    https://[您的GitHub帳號].github.io/IoT-DIC2-MultipleLR/
